# 坦克动荡（Pygame）

一个受经典迷宫坦克对战游戏启发的本地桌面游戏。支持单人挑战 AI 和同键盘双人对战；炮弹会在墙壁上反弹，击中坦克即可得分并开始下一回合。

## 启动

需要 Python 3.9 或更新版本：

```bash
python3 -m pip install -r requirements.txt
python3 tank.py
```

## 操作

| 操作 | 玩家 1 | 玩家 2 |
| --- | --- | --- |
| 前进 / 后退 | W / S | ↑ / ↓ |
| 左转 / 右转 | A / D | ← / → |
| 射击 | 空格 | 回车 |

主菜单按 `1` 开始普通单人模式，按 `2` 开始双人模式，按 `3` 挑战 AI 1.2。AI 1.2 模式中，玩家使用 P1 的 W/A/S/D 和空格键控制黄色坦克；蓝色坦克使用与上一版相同的寻敌、瞄准、开火规则，并在危险时由纯闪避网络控制移动。该模式每局生成一张新迷宫，双方出生点随机。游戏中按 `Esc` 暂停；暂停时按 `R` 重开比分，按 `M` 返回菜单。每名玩家最多同时有 5 发炮弹在场，炮弹可反弹 9 次。

## 强化学习实验

`tankai.py` 是一个不依赖深度学习框架的第一版表格 Q-learning 实验。训练时不绘制画面，使用与游戏相同的迷宫、移动和炮弹规则，对手是现有的规则 AI。

```bash
python3 tankai.py --episodes 500
python3 tankai.py --watch
```

模型默认保存为 `tankai_qtable.json`。也可以用 `--model 路径` 指定文件，用 `--seed 数字` 设置随机种子。`--watch` 中黄色坦克由学习策略控制，蓝色坦克是规则 AI；按 Esc 退出。

本版把完整地图压缩成前方及两侧的近距离墙壁探测，把炮弹压缩成最近的来袭炮弹方向。奖励仅在击败敌方（+1）或被击败（-1）时产生，平局为 0。它是训练流程原型，不能保证在复杂随机迷宫中训练出高胜率。

## 小型神经网络版

`tank_nn.py` 使用 NumPy 实现了小型 DQN，不需要安装 PyTorch。输入包含完整迷宫墙体、双方坦克位置与方向，以及最多 10 发炮弹的位置、速度和归属。网络有三层隐藏层、每层 128 个神经元，输出仍是 18 个动作的价值。训练使用经验回放和目标网络，胜负奖励与 Q 表版相同。

```bash
python3 tank_nn.py --episodes 2000
python3 tank_nn.py --evaluate 100
python3 tank_nn.py --watch
```

神经网络版默认使用固定迷宫，但每局随机选择相距至少 6 格的两个出生点。当前版本使用相对位置与速度、按距离排序的炮弹输入、三步回报和更长的探索期，并区分击败与超时。训练每 200 局在另一批出生点上评估一次，最佳模型保存为 `tank_nn_v2_best.npz`，最新模型保存为 `tank_nn_v2_best_latest.npz`。重复运行训练会从头开始；如需从最佳模型继续，使用 `--resume`。

`--evaluate` 在固定迷宫上输出胜、负、平局、自身炮弹击中次数和平均局长；加上 `--random-map` 可以测试随机迷宫。两种评估使用相同的全图随机出生规则。`--model 路径` 可指定模型文件。旧模型的输入格式与当前版本不同，不能直接加载。

```bash
python3 tank_nn.py --evaluate 100 --random-map
```

## 混合对战策略

`tank_hybrid.py` 使用已训练的 `tank_nn_v2_best.npz`。规则规划器负责迷宫寻路和确认射线畅通后的射击；当敌方炮弹的短期轨迹接近自身时，神经网络接管前进、后退和转向决策。这个策略是**规则规划加神经网络闪避**，不是纯神经网络策略。

```bash
python3 tank_hybrid.py --evaluate 200 --seed 2026
python3 tank_hybrid.py --evaluate 200 --seed 31415
python3 tank_hybrid.py --evaluate 200 --seed 2026 --random-map
python3 tank_hybrid.py --evaluate 200 --seed 2026 --planner-only
python3 tank_hybrid.py
```

最后一条命令会打开可视化对局，按 Esc 退出。`--planner-only` 关闭神经网络接管，用于衡量神经网络部分的贡献。固定地图上，混合策略在两组各 200 局的独立评估中分别赢 163 局和 177 局；相同出生序列下，单独使用规则规划器赢 158 局。纯神经网络版仍可通过 `tank_nn.py --watch` 查看。

## 纯神经网络闪避实验

`tank_dodge.py` 是独立的闪避训练场，不依赖寻路或射击规则来控制坦克。场地有边界与少量障碍墙，每隔 0.65 秒从八个方向轮流发射瞄向坦克的炮弹。模型只使用坦克朝向下 130 像素范围内的八条墙壁探测射线，以及最近六发炮弹的距离和相对角度；相邻两帧的观测拼接，用于推断炮弹运动。网络有两层、每层 64 个神经元，输出前进／停止／后退与左转／不转／右转的九种动作。每存活一帧获得 `1/30` 的奖励，死亡后本局结束，最长 20 秒。

```bash
python3 tank_dodge.py --episodes 2000
python3 tank_dodge.py --evaluate 200 --seed 2026
python3 tank_dodge.py --watch
```

最佳模型保存为 `tank_dodge_best.npz`。在未参与训练的两组各 200 局评估中，平均存活时间分别为 3.11 秒和 3.08 秒；相同条件下静止约 1.09 秒、随机移动约 1.20 秒。训练场中的纯闪避模型仍不能稳定存活完整的 20 秒；主游戏第 3 项现已将它与寻敌和攻击规划器组合成 AI 1.2。

## AI 对战模拟

`tank_duel.py` 让上一版最强混合 AI 与“新闪避网络 + 同一套寻路和攻击规则”的 AI 对战。两者都使用相同的迷宫寻路、瞄准条件和开火节奏，只在敌方炮弹危险时选择不同的移动网络。每局同时决定动作、再同时移动和射击；同一帧双方都被击中时判平局。默认固定地图、随机出生点，每个座位分别模拟 200 局。

```bash
python3 tank_duel.py
python3 tank_duel.py --watch
```

`--watch` 显示实时对局，按 `P` 暂停、`N` 下一局、`Esc` 退出；加上 `--swap` 可交换座位。模拟结果可复现：`--seed 2026` 时，双方各坐一次 200 局，新闪避 AI 总计 229 胜、旧最强 AI 143 胜、28 平；`--seed 31415 --games 100` 时，新闪避 AI 总计 131 胜、旧最强 AI 62 胜、7 平。这里的新闪避网络是在独立训练场训练的，未在正式对战中继续训练。

### 演示画面

```bash
python3 tank_demo.py
```

黄色坦克是混合 AI，蓝色坦克是原规则 AI。顶部显示比分和当前控制状态：通常由规划器寻路和瞄准；敌方炮弹在短时间内可能接近自身时，显示“神经网络接管移动”。按 `P` 暂停、`N` 开始下一局、`F` 在固定与随机地图间切换，按 `Esc` 退出。也可用 `python3 tank_demo.py --random-map` 直接在随机地图开始。
