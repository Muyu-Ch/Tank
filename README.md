# 坦克动荡（Pygame）

本地坦克迷宫游戏。单人模式对战 AI **曼施坦因**，也支持本地双人对战。每局生成随机地图和随机出生点，炮弹可以在墙壁上反弹。

## 启动

需要 Python 3.9 或更新版本：

```bash
python3 -m pip install -r requirements.txt
python3 tank.py
```

主菜单按 `1` 挑战曼施坦因，按 `2` 开始本地双人对战。

| 操作 | 玩家 1 | 玩家 2 |
| --- | --- | --- |
| 前进 / 后退 | W / S | ↑ / ↓ |
| 左转 / 右转 | A / D | ← / → |
| 射击 | 空格 | 回车 |

游戏中按 `Esc` 暂停；暂停时按 `R` 重开比分，按 `M` 返回菜单。

## 曼施坦因

玩家记录的 100 局对战成绩为：**玩家 9 胜，曼施坦因 91 胜**。

曼施坦因用战术规划器寻找直射和反弹射击路线；移动时使用神经网络闪避，并用真实炮弹物理检查短时间内的碰撞。它还会提前预测较远处的密集火力，沿迷宫通路寻找远离弹群、保留出口的位置，再恢复追击。

AI 的运行代码集中在 [tank_ai.py](tank_ai.py)，唯一的模型数据是 `manstein.npz`。游戏入口是 [tank.py](tank.py)。旧训练脚本及未采用的候选模型不属于运行版本。
